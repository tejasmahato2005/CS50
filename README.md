# 🎓 CS50x: Introduction to Computer Science

This repository contains my solutions and project files for **CS50x: Introduction to Computer Science**, Harvard University's introductory course on computer science and programming.

---

## 📚 Course Overview

The course covers fundamental concepts of computer science, algorithms, data structures, software engineering, and web development using various programming languages including **C**, **Python**, **SQL**, **HTML**, **CSS**, and **JavaScript**.

---

## 📁 Repository Structure

Below is an overview of the directories and problem sets included in this repository:

| Directory | Topic / Technology | Description |
| :--- | :--- | :--- |
| `plurality` | C / Algorithms | Simulates a plurality election using simple vote counting. |
| `runoff` | C / Algorithms | Simulates a runoff election with ranked-choice voting. |
| `filter-less` | C / Image Processing | Applies image filters (grayscale, sepia, reflect, blur) to BMP files. |
| `recover` | C / Memory | Recovers deleted JPEG images from a memory card dump. |
| `volume` | C / Audio Processing | Modifies the volume level of WAV audio files. |
| `speller` | C / Data Structures | Implements a fast spell-checker using hash tables. |
| `inheritance` | C / Data Structures | Simulates the inheritance of blood types across generations. |
| `movies` | SQL | Executes SQL queries to analyze IMDb movie data. |
| `fiftyville` | SQL | A database mystery game solved using SQL queries. |
| `songs` | SQL | Analyzes Spotify song data using SQL queries. |
| `sentimental-hello` | Python | Introduction to basic Python syntax. |
| `sentimental-mario-less` | Python | Re-creation of the Mario pyramid in Python. |
| `sentimental-readability`| Python | Calculates reading readability levels using the Coleman-Liau index. |
| `sentimental-cash` | Python | Calculates the minimum number of coins needed for change. |
| `dna` | Python | Identifies individuals based on short tandem repeats (STRs) in DNA samples. |
| `homepage` | HTML / CSS / JS | A personal responsive website built using front-end tech. |
| `trivia` | HTML / CSS / JS | An interactive trivia webpage with multiple-choice questions. |
| `birthdays` | Web / Flask / SQLite | A web app to keep track of friends' birthdays. |
| `finance` | Web / Flask / SQL | A web app allowing users to manage portfolio stock trading. |
| `project` | Final Project | My original final project submission for CS50. |
